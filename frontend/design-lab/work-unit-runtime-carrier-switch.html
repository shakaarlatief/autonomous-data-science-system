Can live runtime use one switchable carrier per work unit instead of stacking multiple runtime signals?

Runtime remains conditional and separate from category, project disposition and current-focus membership. This refinement compares two deliberately exclusive live-runtime carriers: a dot with a dynamic ring, or an explicit runtime tag with a circulating perimeter trace.

Held semantic rule One runtime carrier per live work unit No runtime episode means no runtime carrier.
Convergence hypothesis

Choose a compact instrumental carrier or an explicit textual carrier

The two carriers are alternatives, not a hybrid. A global switch changes every live-runtime box together. Clicking the visible runtime carrier on one box flips only that box, creating a local override. Clicking its replacement flips it back.
