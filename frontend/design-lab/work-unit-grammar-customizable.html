Product architecture implication

Customization belongs above the semantic project model

A future production implementation can persist a user-level appearance profile, optionally overridden per project. The style layer may choose shape and surface treatments, while semantic category mappings, accessibility constraints and state meaning remain governed by ADS. This design-lab page uses browser-local persistence only as a prototype of that interaction contract.
