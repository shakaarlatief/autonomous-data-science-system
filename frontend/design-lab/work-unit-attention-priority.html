ADS Cockpit Design Lab · Slice 02J · Attention Priority

How should a work unit say “pay attention to this now” without stealing meaning from category, disposition, status or focus?

This slice deliberately narrows the broader importance / priority / relevance problem to one provisional signal: elevated attention priority. It tests visual carriers only. It does not freeze a priority scale, relevance score, scheduling policy or ranking algorithm.

Held semantic separation focus membership ≠ attention priority ≠ operational status Priority is tested as an orthogonal emphasis signal, not another work-unit category or runtime state.
Bounded semantic question

Priority should answer which visible work deserves more attention, not whether it is running or blocked

A Current work unit may be high priority while Running, Blocked, Waiting for Human or carrying no live operational state. Current-focus membership still answers whether the work belongs in the emphasized process set. This experiment asks only how a high-attention signal should look when those other channels already exist.

Category hue remains category-owned Disposition stays top-right Status stays bottom-right Focus suppression remains separate Priority must survive mixed categories No priority ontology frozen
