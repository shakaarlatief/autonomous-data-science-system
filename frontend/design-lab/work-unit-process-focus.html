How should the Cockpit keep future and contextual work visible without letting it compete with the current process?

The accepted neutral-tag + tone disposition treatment is held constant. This slice adds a separate focus lens whose membership can be curated by the user without deleting or changing the underlying work units.

Semantic boundary Disposition ≠ focus membership ≠ view emphasis
Bounded design question

Keep context available, but let the actual process dominate

The focus set is explicit and user-adjustable in this experiment. Adding or removing a work unit from the focus set changes only the current-process lens, not its category, disposition, runtime state or existence in the project.
