ADS Cockpit Design Lab · Slice 02D · Connector Directionality

Use the same restrained arrow treatment for every direction state.

Dots, frame sockets and arrows are separate connector treatments. Hover is a separate interaction mechanism that may reveal or emphasize whichever treatment is active. This page therefore isolates arrows only: no dot-plus-arrow or socket-plus-arrow combinations.

Design question

Can the original edge-connected arrow treatment cleanly express all relation directions?

The four lanes use the same nodes, curve geometry and arrow shape. Only the semantic direction state changes. The arrow tip docks directly to the relevant work-unit edge, using the same treatment that was already preferred in the earlier connector slice.

Human clarification

Connector treatment and hover behavior are orthogonal

Clean lines, micro dots, frame sockets and direction arrows remain useful connector treatments. Hover is not another terminal that must be combined with them. It is a behavior that can later reveal or emphasize the selected treatment. This directionality experiment therefore shows arrows by themselves.

Semantic rule The relation model determines no direction, forward, reverse or bidirectional. If arrows are used to present that relation, their placement follows that semantic state exactly.
