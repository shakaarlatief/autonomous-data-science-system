# Phase-C Project Cockpit Decision Ledger

**Date:** 2026-08-28  
**Status:** Current exhaustive recovery ledger for the next-generation Cockpit design phase  
**Scope:** Research 037 through Research 088, including selected results, provisional working defaults, deferred questions, rejected alternatives and diagnostic evidence.  
**Authority:** Routing/disposition ledger. Accepted specifications, foundations and explicit human-reviewed selections remain authoritative for their semantic scope. The implementation manifest governs exact source reuse for holistic integration.

## Why this ledger exists

Phase C intentionally explored many alternatives. The first holistic integration proved that preserving only the names of selected mechanisms is not enough, but the opposite mistake would also be dangerous: treating every experiment that exists in the repository as something that should be combined into the product.

This ledger therefore makes the disposition explicit.

```text
DESIGN HISTORY
    everything we explored remains preserved

IMPLEMENTATION OBLIGATION
    only selected/held mechanisms and explicitly named provisional working defaults
    are allowed into the next holistic build
```

## Disposition vocabulary

```text
SELECTED / HELD
    human-reviewed direction that must survive integration unless explicitly revised later

FOUNDATIONAL
    promoted product principle that constrains implementation but may not define one exact visual artifact

PROVISIONAL WORKING DEFAULT
    temporary implementation needed to continue; must remain visibly/procedurally provisional

DEFERRED / PRESERVED
    unresolved future question; evidence remains available but no current implementation winner exists

REJECTED
    reviewed alternative that must not silently return as current product behavior

HISTORICAL / DIAGNOSTIC
    useful evidence or failed attempt; not a product source of truth

PROTOCOL / PROCESS
    development or evaluation method rather than a Cockpit visual mechanism
```

# Cross-cutting held product rules

## World and visual hierarchy

```text
G4 Adaptive Hybrid
Dark-first current baseline
ambient motion lower salience than semantic activity
Lively travelling-current cadence
major-grid glints remain independent/quiet
fixed authored ambient repetition rejected
```

## WorkUnit semantic-channel separation

```text
category
    != project disposition
    != runtime state
    != blocked progress constraint
    != attention/priority
    != selection UI state
    != current-process focus lens
```

Integration must not collapse these channels merely because a single component renders them together.

## Appearance versus semantics

Foundation 023 remains binding:

```text
ADS owns semantic meaning
user may choose only approved semantically safe presentation dimensions
```

Current proven appearance dimensions include:

```text
Box shape
    Normal
    Subtle

Micro design
    None
    Micro material
    Micro light

presets
    Clean
    Structured
    Rich
```

The exact production persistence mechanism remains open. `localStorage` in design-lab fixtures is proof-of-concept only.

## Connector semantics versus presentation

Foundation 024 remains binding:

```text
relation meaning and directionality
    system-owned

terminal treatment and hover behavior
    presentation mechanisms
```

Direction cannot be invented, reversed or removed by appearance preference.

## Conversation

```text
Quiet Graphite baseline
project-general + WorkUnit-scoped conversations
Boxes / Text rail
A6 Adaptive Anchor
no redundant floating A6 source card
Grid + X5 + Deep Dive access
full-focus + co-present modes
source work-state restoration
compact native composer
```

## Promoted Specification 008 capabilities that remain required

The Phase-C visual work does not revoke the promoted V1 interaction architecture. Holistic integration must retain:

```text
finite navigable world distinct from semantic project plane
2D movement and recovery
bounded geometric zoom
fit/reset/recenter
Jump/search
viewport-aware orientation
compact/fold-away chrome
collision-safe floating surfaces
true browser fullscreen with graceful fallback
URL-addressable important focus state
keyboard accessibility
reduced-motion support
selective specialist mounting / reachability != simultaneous mounting
```
