## Architecture priority

The preferred next discriminating experiment is:

```text
authorized local Windows PDF
    -> ADS bounded authority/provenance reader
    -> standard MCP application/pdf resource
    -> ChatGPT host

```

If this path works, ADS may not need custom page-image transport for ChatGPT PDF understanding. `codex.document_read` can remain the deterministic text/provenance path, while the first-party PDF capability owns richer visual/document interpretation.

If it fails, Checkpoint 289's authenticated loopback transport candidate remains available for resumed qualification.
