## Actual experimental action and observed source-relative outcomes

Used all 65 exact historical Git documents to execute **130** new synthetically worded relation questions, 65 forward and 65 reverse, derived from a real **110-edge literal repository-path mention graph**. **70 positive** and **60 structurally empty** queries included; two over-K=10 cases included. Typed graph index returned **208/220** actual required mention-source instances, exactly the 10-result ceiling, and emitted no source for all 60 no-reference questions. The graph oracle is computed from the same source parser, so this is **expected functional self-consistency**, not independent gold or architectural superiority.

The lexical baseline returned **110/220**, B1 inferred subject **104/220**, generic B2 literal path hop **132/220**, previous three-way RRF **126/220**. Naïve graph+lexical fusion returned **186/220** but emitted **600 unsupported source slots** across 60 structurally empty tasks. A gated combination preserved **186/220** while correctly emitting **zero** on all those 60. The synthetic typed-query router exactly matched graph-index behavior, and also preserved all **74** historical nonrelation query router outputs by exact trace parity.

Full exclusive-create output: **1,692,786 bytes**, SHA-256 `99206720df7dfa6deb788f4abd8428137a55f5ee68962e83f08da79a7775c399`, with complete source-level per-query ranks, expected paths, cost proxies and scores. No actual private C01/C02 material was accessed or modified.

## Boundary and immediate next engineering objective

These results qualify the engineering mechanism of a bidirectional, path-grounded, empty-aware relation index. They do **not** qualify a governed source-owned editorial B2 link, actual selective B3 concern, meaningful cross-document reasoning, paraphrase-resistant intent identification, real-world nonexistence evidence, independent new user gold, formal 12-primary Research 513 acceptance, architectural target selection, or a physical migration.

The immediate technical opportunity is a separate genuinely differently sourced question/evidence sampling family with real semantic relation or lifecycle labels, plus tests of paraphrased natural-language relation intent, explicit-source authority and historical version boundaries. Do not tune the just-exposed 130 grammar-specific tasks into apparent generalization.
