## Decorative motion is allowed

The current motion model explicitly distinguishes:

```text
SEMANTIC MOTION
    communicates real changing project/runtime state
    higher salience
    must remain interpretable

AMBIENT MOTION
    decorative / atmospheric
    lower salience
    slow and sparse
    may exist purely to make the world feel polished and alive
```

The earlier semantic rule remains valid for moving project relations, but it no longer implies that every moving pixel must encode project state.

Ambient behavior is acceptable when it remains clearly subordinate, does not imitate semantic state colors/behavior, supports long-session comfort, and degrades cleanly under reduced motion.
