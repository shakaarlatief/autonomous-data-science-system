However those tests do **not** execute G013 over the new experiment-local source transition.

Therefore the full-repository validation defect is **preexisting**, not created by the new experimental source move, and is not fixed or reclassified as PASS here.

Two separate issues must be distinguished:

1. Natural production source discovery does not automatically treat an isolated experiments/ carrier as live production canonical authority. This is expected scope isolation, not an excuse to bypass production validation.
2. Direct main-repository validation at the three checked commits reports preexisting source digest mismatch. A full G013 refresh on those main-repository commits is not qualified by our isolated G006 result or by existing G013 regression tests.

Next work can use a source-eligible, physically isolated but genuinely original-source-bound sandbox with the *actual production G013 generator*, or a separately qualified adapter interface. That choice must respect Research 513 common-world parity, not introduce a synthetic source-only baseline as the formal corpus, and not change production authority without authorization.
