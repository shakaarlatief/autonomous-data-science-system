This directory preserves rich interaction evidence that motivated the activation/orchestration/self-hosting bootstrap program.

It exists because a central failure mode of the current project-development architecture is not durable knowledge loss, but failure to **activate and operationalize knowledge that already exists** when the owner raises a relevant observation or request.

The files here are not governing architecture. They preserve owner intent, examples, causal reasoning, and unresolved design pressure so later work does not depend on manually reconstructing prior ChatGPT conversations.
