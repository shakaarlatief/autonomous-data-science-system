## 8. Grouping correction

Claude-04's proposed sampling mechanism was too permissive if it allowed a sampled class to populate unreviewed MUST_SPLIT pairs.

V0.3 instead uses:

    deterministic candidate generation
        ->
    individual confirmation of every pair that enters MUST_JOIN or MUST_SPLIT
        ->
    all other pairs UNCONSTRAINED

Sampling may decide which candidate families are worth inspecting.

It cannot establish truth for unseen pairs.

This keeps grouping bounded without converting class heuristics into hidden ground truth.
