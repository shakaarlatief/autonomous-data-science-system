## 1. A real experiment, with a deliberately limited scientific claim

The owner instructed us to stop letting infinite answer-set qualification prevent R0-P03 engineering execution. Checkpoint 918 therefore supplied a real twelve-question, source-cited, exposed primary-task fixture and an implemented B0 text retrieval baseline over 60 identical original Git sources, with 20 held-out originals. This checkpoint proceeds to four materially different executable mechanisms: frozen B0, topical subject membership B1, source-written editorial link navigation B2 and selective concern navigation B3. We did **not** pretend that reweighting a heading index is an implementation of a structured B1/B2/B3 arm.

Nonetheless, this is **not yet a qualified Research 513 formal B0–B4 comparison**. The exposed coordinating model wrote the previous questions/answers and saw their B0 rankings before selecting the new B1/B3 source annotations. The 60 authored source-adjacent overlays are a real experimental representation of the proposed source-local metadata model, but they are **not original Git carrier-authored declarations, not independently verified correct and not governed source ontology**. They do not modify the actual source carriers; the experimental manifest is just an input fixture. The W5 vocabulary, by contrast, is a real previously preserved historical research vocabulary with 18 substantive assignable subjects and 6 nonassignable parents. B2's surviving three references were copied verbatim from real original source lines, but a literal reference does not prove a complete nonredundant carrier-to-governing relationship.

The score is an exposed one-required-source discovery metric only. Nothing here verifies complete answer correctness, no new governing authority is implied by a source's `Status`, and no change to the architecture is selected.

## 2. B1: authentic historical subject vocabulary, but explicitly new source-adjacent memberships

Reused the original `experiments/project_knowledge_subject_navigation_t1_v02/subject_catalog_candidate_v02.json` subject catalog, exact SHA-256 `53c5cb65caccd1a9123f5d6da2e5738f618b383339c5bcfcf1d58fb9f5399495`. This defines **18 assignable** substantive semantic subjects, **six nonassignable** navigation parents, multi-parent `broader` relations and source-owned membership rules. The original catalog stores **no** source membership.

The exposed model then wrote **60** exact-source-identity-bound *experimental source-adjacent annotations*, containing **94** subject memberships and one preferred navigation route for each carrier, with original Git blob SHA-256 and exact H1/`**Scope:**` line witness. Six of those paths also had W5 historical membership at the older original revision `4b94ffe183ff7af72cef6ee7492b4ba2f30c11ef`; these historical annotations are recorded as non-current historical comparison, never silently treated as valid current source-authored membership.

Query-to-subject retrieval uses only the frozen catalog label/description/include clauses and the existing fixed non-stopword vocabulary. Cosine similarity over unique query words selects the strongest substantive assigned subject per document, so carriers with many labels cannot simply accumulate unbounded advantage. The source subject channel is combined with identical B0 top-ten using fixed reciprocal-rank fusion (K=60). The broader/preferred-parent graph is validated as acyclic and remains only a navigation hierarchy, not source authority.

**New metadata burden:** 94 source-subject memberships across 60 carriers, frozen as **exposed editorial** work, not free prior investment. Measured human minutes are unavailable.

## 3. B2: genuinely source-written editorial navigation candidates, not invented governing links

An original-Git-only extractor inspected the actual sixty source bodies for direct literal `docs/.../*.md/json/py` mentions. It excluded fenced-code occurrences, links to other/unavailable carriers and explicit native `**Declared references:**`, `**Authority:**` and `**Parent:**` headers because those have no legitimate exclusive B2 advantage over the shared V03-native relation substrate.

The resulting frozen source-local candidate witness graph contains exactly **three distinct directed pairs**:

| Original carrier | Direct originally mentioned carrier | Type |
| --- | --- | --- |
| `docs/CURRENT_STATE.md` | `docs/DECISIONS.md` | Nonfenced source-written path in historical continuity text |
| `docs/DECISIONS.md` | `docs/CURRENT_STATE.md` | Nonfenced prose reference |
| `docs/research/156_real_current_state_decomposition_and_source_ownership_audit.md` | `docs/CURRENT_STATE.md` | Explicit source-owned scope reference |

The extractor excluded **585** fenced code mentions, **16** native header references and **46** references to excluded/non-build/self files. Each of the three remaining edges retains its original source and target hashes, exact source line number/full content/line SHA-256 and uncertainty about its semantic type. None asserts governing authority or accepted relation correctness. The real source current-state file was unusually long, and extracting such edges from its full body adds source-read effort beyond B0's first-12,000-character search cap. That cost asymmetry is disclosed and forbids claiming a parity-qualified formal comparison.

B2 navigates actual one-hop edge neighbors from B0 candidates with frozen outgoing propagation `0.6` and incoming propagation `0.2` times the originating B0 rank weight `1/(60+rank)`. It saves every real line-witness-based traversal, scores only the same 60 original paths, and never creates a shortcut from reference answer IDs.

**Finding:** The historical source graph is too sparse to provide material aggregate benefit here. Fabricating complete B2 editorial links based on gold references would contaminate the experiment.
