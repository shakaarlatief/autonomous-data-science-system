## 4. Non-negotiable scientific/architectural constraints

Any prospective redesign should preserve unless a separately approved owner amendment explicitly changes the rule:

1. No invented or self-certified owner acceptance, accepted J1 effect, natural-owner J2 realization, historical CI execution, authority/currentness, or false claim of absence. Unknown and unavailable evidence must be first-class.
2. Same source bytes, temporal horizon, role/evidence semantics, common V03 substrate, query definitions, budgets and scoring conditions across treatment arms within each comparison world; controlled treatment differences only.
3. Information-role owners separate from navigation metadata. B1/B2/B3 metadata cannot silently become authority. B2's additional editorial-about relations must be tested for independence from governing lineage/J2; B3 concerns must not simply rename B1 topics.
4. A real independent, arm-neutral reference and maintenance evidence basis; no scoring the original Research 217 B1-grounded nine-task gold as if neutral. Holdouts and evaluator exposure must be credible for the actual author/evaluator route (Level B per Research 576).
5. Real whole-system relevance: source discovery, cross-plane route, fresh-agent reconstruction, impact analysis, exact authority/evidence, abstention, human browseability, authoring/review burden, maintenance, deletion/rebuild, public/private behavior, and adapter feasibility.
6. No retroactive reinterpretation of Research 513/559/576 hard gates or earlier results. The current >=10/12 primary, >=8/9 neutral historical, zero false authority, heldout F1 >=0.80 where applicable, <=10% authored metadata churn, rebuild safety and complexity preference remain in force until an exact prospective owner-approved alternative exists.
7. A falsifiable decision path: actual scored results or a specific bounded AMEND/REOPEN/HOLD; never an unbounded chain of opportunistic evidence-gathering as a default.

## 5. Alternative strategies worth a genuine challenge

**Option A, continue original single-world historical full-answer experiment as written.** Strength: stringent same-repository realism, historical authority sensitivity and unmodified original gates. Weakness: C01/C02/full-scope evidence shows the currently selected source horizon and full-closure admission approach repeatedly fail; exact J1/J2 truths can remain permanently unavailable. Need an explicit new qualified evidentiary source or demonstrated closure path before repeating. It cannot be declared impossible categorically.

**Option B, a two-environment, evidence-tiered prospective comparison (leading DISCUSSION CANDIDATE, not a selection).**
- Controlled, realistic project-history environment: independently authored and versioned governing decisions/effects, actual test/execution/evidence outcomes, explicit negative controls, successor/lineage, implementation changes and derived orientation, in representative human-readable and machine-readable carriers. All mechanisms receive the same exact controlled, *scenario-true but explicitly synthetic*, V03-native common state. This tests demanding authority/succession/coverage semantics without pretending it happened historically in ADS.
- Real historical environment: independently chosen realistic user information needs and original Git-pinned repository sources; score only propositions independently established by the permitted source evidence and separately score epistemic limitation/abstention. Unknown actual owner/CI/recovery claims remain unknown; do not award invented completeness. Report source world admission and answerability yield transparently, including failed candidate tasks, rather than secretly choosing only answerable easy examples.
- Score those environments separately. A strong synthetic score must never compensate for a real-world false-authority violation or a failure of natural-document discovery; a real-world partial source finding must not count as complete governing truth. Require mutually independent creators/reviewers and all arms unchanged on the same task worlds.

**Option C, evidence-tiered real-source-only navigation test plus targeted controlled semantic invariants.** Less setup, potentially sufficient if the remaining physical decision concerns only marginal retrieval/navigation. Risks: insufficient coverage of J1/J2/J3, lineage, hard false-authority and hypothetical future operational workflows. Its adequacy must be demonstrated, not assumed.

**Option D, conclude that available R0-P03 experiments are only exploratory and carry a bounded unresolved navigation choice to the owner/physical-target decision.** Could be appropriate if exact decision value is small and downstream implementation can safely defer it, but is a MATERIAL change to the original preselection gate/selection semantics and requires explicit prospective owner disposition. Cannot silently mark PASS or assert the candidate is fully selected.

Avoid the false dichotomy between unlimited historical reconstruction and arbitrary synthetic benchmark. The critic should consider a different architecture of the experiment if stronger.

## 6. Candidate prospective procedure for Option B: explicit stages, not executed authorization

**D0. Specify the actual decision to be made.** Write a conditional decision table: B0 alone vs B1 subjects, B2 editorial links, B3 concerns, B4 structured+semantic retrieval, and at least a simple task-neutral lexical/heading/character-hybrid baseline if the current weak B0 implementation unfairly advantages add-ons. Define what empirical outcome would select, amend or eliminate a method. Distinguish extra navigation value from mandatory common V03 typed relations. Freeze before new result observation.

**D1. Define admissible reference claims by world.** Controlled world: truth defined by scenario-authority acts, exact versions and execution receipts created by its independent designer; verify deterministic source-to-state consistency, tamper/absence/contradiction cases. Real world: classify each requested claim as VERIFIED_SOURCE_FACT, SOURCE_REPORTED_CLAIM, VERIFIED_EXTERNAL_EXECUTION, VERIFIED_OWNER_ACT (only if actual independent evidence exists), UNRESOLVED, or OUT_OF_SCOPE. Source-reported claims do not escalate. Specify falsifiable support, denial and safe abstention criteria. Separate retrieval quality from correctness and intentional abstention. Do not call "no source found" proof that an event did not happen.

**D2. Construct a source/task sampling plan before seeing arm outcomes.** Maintain cold start, cross-plane discovery, impact/evolution and authority/recovery as distinct categories; include exact source lookup, relationship-dependent tasks, temporal/supersession, negative/evidence-limited cases, context-budget pressure and authoring maintenance. Use independent needs and an objective candidate-sampling/answerability audit; preserve candidate failures in the denominator of *sampling yield* and never post-hoc remove hard questions to create a green pass. Decide explicitly, with owner approval, how new 12-primary and historical nine tasks distribute across controlled/real worlds and what formal thresholds mean. Existing Research 513 scores are NOT automatically transferrable. Original W5 65 sources, 9 scenarios and 65/24 calibration stay immutable historical evidence; neutral prospective legacy re-adjudication remains necessary unless separately amended.

**D3. Establish one comparable common substrate per world.** Every arm receives source roles, temporal provenance, exact authority class, accepted effect/lineage/J2/receipt edges wherever genuinely authenticated or scenario-defined, lexical retrieval and derived non-authoritative orientation. In the real world absent evidence remains explicit UNKNOWN; documentary-only edges are separate. In the controlled world true accepted effect/J2 evidence is generated as part of the synthetic scenario, not represented as real ADS production acceptance. Freeze and compare substrate digests. Avoid giving B0 a deliberately weak arbitrary 12,000-character body truncation when other methods access full records; equal source/context budgets and a strong fair shared lexical baseline are necessary.

**D4. Freeze genuinely distinct treatments before scored exposure.** B1 real subject navigation with prospective catalog/membership evolution and measured author cost; B2 genuinely additional source-owned editorial/about edges distinct from J1/J2/lineage; B3 governable limited cross-cutting concern declarations with overlap tests against B1; B4 explicit structured parent chosen by a pre-score rule plus an actually justified semantic model. If B2 contributes no meaningful nonredundant relations, record that as a real architectural finding instead of fabricating edges. If a fair B4 cannot run, follow an explicitly approved prospectively frozen reduced-family protocol and label the coverage limitation. Source annotations and test tasks must be separated so metadata is not written after seeing expected rankings.

**D5. Qualify independence, evaluation and heldout evolution.** Use Research 576 Level B with actual role, tool, source and full-reference exposure checks, not mere "fresh session" labels. Preserve a reference custodian accessible to reviewers but not arm authors; distinguish source-proven fact from gold author declaration. Use independent scorer and a second fresh judge where qualitative answer assessment requires it. Evaluate real answers, verified citations, authority errors, abstention type, costs, median tool/context load, owner browseability, annotation minutes, heldout maintenance F1/churn and rebuild after deleting indexes. Reproducible scoring, metamorphic changes and explicit evaluation of changing/corrected/withdrawn evidence matter more than raw retrieval rank.

**D6. One finite trial and governed stop.** Once independently qualified source/task references and actual arm parity pass preflight, freeze immutable inputs and run once under prospectively specified repetition/adjudication. If no viable reference capacity after a fixed bounded attempt, stop with specific source/reference HOLD, and propose a concrete owner amendment or architecture-decision deferral. If all methods fail at substantive semantic requirements, record AMEND/REOPEN as justified. No automatic new cohort, no silent relaxation of source authority, and no selection based on posthoc exposed outcomes.

## 7. Why this candidate may itself be wrong (required critique)

- A two-world program could double experimental effort and never solve independent authorship/custody. It must earn its complexity with decision-relevant discrimination, not merely a more elaborate protocol.
- A synthetic controlled world might overrepresent explicit typed relationships and flatter a graph/ledger-aligned architecture, while underrepresenting messy real documents and authoring maintenance. Require adversarial negative cases, source realistic noise, and independently audited construction.
- A real-world test with source-relative answer gold can make an architecture appear safe by abstaining on all difficult questions. Score calibrated abstention and factual question coverage separately; do not award every UNKNOWN as success.
- Retrospectively using the known 12 exploratory Route-B rankings to select "representative" future tasks or a particular B4 parent is leakage.
- The equal V03 substrate may be logically required for testing each add-on, but not all historical semantic relationships need to be classified as true. The critic must decide where the line is.
- Original Research 513 gates cannot be copy-pasted to a new mixed-world benchmark without a carefully justified prospective owner decision. Proportional rigor is desirable; opaque convenient threshold changes are not.
- It remains possible that simpler Option C or a different experimental design yields a stronger decision with fewer untestable assumptions.
