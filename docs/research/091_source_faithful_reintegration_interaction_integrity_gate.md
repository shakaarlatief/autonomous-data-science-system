## 1. Why this milestone exists

Research 088 showed that the first holistic Cockpit failed because accepted browser implementations had been manually reinterpreted during integration. Research 089 recovered exact implementation provenance, and Research 090 proved that all manifest-bound accepted source files on the active branch were byte-identical to their declared historical sources.

The replacement integration therefore followed a different rule:

```text
accepted implementation exists
    -> import/reuse it directly where possible
    -> otherwise port the smallest exact mechanism
    -> keep new whole-product orchestration thin and explicitly provisional
```

The resulting review surface is:


## 3. Navigation contract recovered

The integrated Project Grid now separates spatial movement from zoom:

```text
ordinary two-finger trackpad scroll
    -> pan through project space

native trackpad pinch/spread
    -> geometric zoom around the gesture anchor

pointer drag
    -> alternate pan

keyboard arrows
    -> pan

+ / -
    -> zoom

0 / Reset / Fit / Jump
    -> recovery paths
```

The pinch path retains bounded frame-coalesced deltas and anchor preservation from the promoted Specification 008 interaction architecture.

Transform compositing is held only while navigation is active and released after the gesture settles so Chromium may rerasterize fine content. Translation is aligned to the device-pixel grid after settlement.

This is an implementation-fidelity measure, not a final renderer-technology decision.

## 8. What this milestone proves

It proves that the replacement integration architecture can compose a substantial set of accepted mechanisms without the broad source-reinterpretation failure of the first holistic browser.

It also proves that the integration gate can detect concrete cross-mechanism failures. During this pass it caught missing local resources, dead Deep Dive behavior, transition-sensitive assertions and input/recovery interactions before the work was presented as a baseline.

## 9. What this milestone does NOT prove

This is not closure of the full integrated fidelity gate.

A green automated gate cannot by itself prove:

```text
all accepted micro-interactions have been mounted
all historical visual refinements have been recovered
all ambient dynamics match the latest human-reviewed behavior
the current arbitrary shell geometry is good
zoom rendering is visually sharp enough at every useful scale
Conversation is integrated
all user-configurable presentation dimensions are mounted
```

Human holistic review therefore remains authoritative and is expected to reveal missing or incorrect mechanisms that should then become deterministic tests where possible.
