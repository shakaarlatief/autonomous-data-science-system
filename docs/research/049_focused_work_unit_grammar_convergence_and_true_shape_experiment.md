## 2. New shape question

During review, the project owner asked whether genuinely different overall shapes had been considered, rather than primarily rectangle-like cards with corner/edge modifications.

The current evidence shows that this design dimension has only been partially explored.

W3/W4 and Claude C2 introduced stronger topology, but most tested silhouettes still derive from one rectangular card body plus a local cut, notch, rail or chamfer.

The project owner also supplied direct shape-orientation evidence:

```text
upper-right cut
    liked / promising

upper-left cut
    feels visually awkward
```

A plausible interpretation is that the left side is a stronger reading and scanning anchor. Therefore asymmetric variation on the top/right/bottom may be safer than disrupting the upper-left entry edge.

This is evidence, not yet a permanent rule.

## 4. Evaluation-inspired micro-light distinction

The project owner's positive reaction to M1 Evaluation appears partly tied to its internal light-like gradient treatment.

This should be separated conceptually from H4 resting illumination.

```text
H4 Reduced resting light
    generic ambient node illumination
    held as the preferred control

micro-lumen / micro-light material
    category-level internal surface detail
    local and restrained
    part of category grammar experimentation
```

A category-specific micro-lumen can therefore be tested without increasing the global H4 rest wash.

## 5. True-shape grammar hypothesis

The new experiment asks:

> Can genuinely different overall work-unit silhouettes improve category recognition and product identity while preserving a coherent professional analytical interface?

The implementation uses an explicit constraint:

```text
preserve the complete left reading edge
allow stronger structural variation on top / right / bottom
```

This is motivated directly by the human preference for the upper-right cut and dislike of the upper-left cut.

The true-shape family includes deliberately different mechanisms rather than one chamfer parameterized across categories:

```text
Question
    upper-right diagonal cut

Investigation
    right-edge inward notch

Validation
    raised / tab-like top geometry

Model
    stepped bottom-right geometry

Evaluation
    right-side beveled / hexagonal-like termination
```

The family remains coherent through:

```text
shared height
shared typography
shared node material baseline
shared scientific marker vocabulary
shared left signature / light anchor
shared H4 hover behavior
shared G4 world
```
