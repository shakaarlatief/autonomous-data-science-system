## 2. Held interaction ladder

The current working interaction ladder is:

```text
compact map work unit
    -> persistent selection using SEL2 Corner Brackets
    -> contextual detail using accepted X5 balanced two-axis expansion
    -> L0 Flat Fields as provisional internal-layout default
    -> specialist workspace / deep focus
```

The next bounded question is therefore the transition between the final two layers.

## 3. Governing promoted architecture

Specification 008 already promotes the product-level requirement:

```text
project map
    -> select meaningful work unit
    -> map recedes / focus transition
    -> full-resolution specialist workspace mounts
    -> perform real analytical work
    -> return to project context
```

It also requires:

```text
everything reachable from the Cockpit
    !=

```

The exact visual/context-retention treatment remains unfrozen, which is the design question isolated here.

## 6. Candidate transition architectures

```text
F0  Hard Replace
F1  Center Stage
F2  Anchored Morph
F3  World Recede
F4  Context Ribbon
F5  Map Frame
F6  Side Context Rail
F7  Portal Lift
F8  Layered Stage
```

### F0 Hard Replace
Workspace fully replaces the map. This is the low-continuity control.

### F1 Center Stage
The project map remains faintly behind a centered full-resolution workspace.

### F2 Anchored Morph
The workspace appears to grow directly from the selected X5 work unit. Tests strongest object continuity.

### F3 World Recede
The whole project world scales back, desaturates and becomes strongly secondary while the workspace dominates.

### F4 Context Ribbon
The map disappears but a compact project-path ribbon preserves location and return context.

### F5 Map Frame
The specialist workspace fills most of the viewport while a visible perimeter of project map remains.

### F6 Side Context Rail
A narrow strip of live project-map context remains beside the workspace.

### F7 Portal Lift
The workspace lifts from the selected object as a distinct rounded layer over a softly retained world.

### F8 Layered Stage
The workspace occupies the front spatial layer while the project map remains visibly displaced behind it.
