## 3. Actual shared source-evidence projection and in-memory lexical search

Using the byte-verified 80 original source files, the probe constructs one deterministic, explicitly **non-authoritative provenance projection**. For every selected carrier it includes immutable original Git revision, blob identity, SHA-256, original path as a **provenance locator rather than semantic identity**, source-byte length and path-derived role hint. All current owner/governing effect, acceptance/currentness, J2 realization, test execution and receipt authenticity fields are **explicitly unadjudicated**. All typed accepted effect/lineage/J2/receipt/completion relation lists remain **empty**, rather than inventing them from co-citation or source position. The 300 recorded literal references have class `LEXICAL_CITATION_ONLY_UNADJUDICATED`, not `REALIZES`, `ACCEPTED` or provenance-confirmed authority.

The program additionally constructs a real in-memory SQLite **FTS5** index from the same 80 original UTF-8 document bodies. Source-free fixed smoke-query hit counts were authority **49**, validation **43**, source **57**. These establish only an executable lexical search capability, **not useful relevance, answer coverage, ranked quality, closed source truth, or scored arm parity**. Raw indexed contents remain inside this execution process.

A canonical byte serialization of the full non-authoritative provenance projection had SHA-256 `ade69476181e5e019fc51f820aa8cf3ee5a9a148082d24dfdc2753c44455f931`. Five separately named **simulated B0..B4 interface slots** receive this exact same base with no additional metadata. All five preserve its identical digest. Negative controls explicitly reject arm metadata overriding common carrier/authority/effect fields and nested attempts to claim governing status. These tests validate a *potential interface isolation invariant*, not an implemented real B0-B4 comparison. The count of actual B0-B4 arm implementations and parity qualifications remains **zero**.

The common projection is **not yet the complete V03-native substrate** required for formal arms: without accepted, source-grounded owner/effect/lineage/J2/receipt edges, it cannot support binding semantic parity or authoritative current orientation.
