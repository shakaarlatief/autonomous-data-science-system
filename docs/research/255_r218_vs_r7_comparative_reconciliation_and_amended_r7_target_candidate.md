    knowledge/governance/architecture/rationale/
    knowledge/governance/architecture/specifications/

        remain carrier-resident

### A3 Human-readable Project-system architecture

        -> governance/architecture/rationale

    normative system contract
        -> governance/architecture/specifications

    how to operate
        -> operations/engineering

    executable/generated/current control state

### A4 Governance / operations distinction

    governance = primarily declarative
    operations = primarily procedural

Binding procedures remain operations.

R8 must preregister an operations/engineering direct-subarea review bound before mapping that corpus.

### A5 Cold-start gate

Human:

    root README -> current orientation         <=1 link
    root README -> Project knowledge root      <=1 link
    root README -> any primary knowledge class <=2 links
    root README -> governing architecture/current authority <=3 links

    machine root anchor locates current routing/authority in anchor read
    current generated orientation/continuation target <=1 additional read

### A6 History without automatic relocation

Keep History as a physical class, but do not move a carrier merely because its lifecycle status becomes historical.

Default:

    stable carrier path
    lifecycle/status update
    generated navigation update

history/ is primarily for:

    born-historical records
    milestone snapshots
    deliberate archival extractions with independent justification

Physical relocation into History is exceptional and requires reference-integrity qualification.
