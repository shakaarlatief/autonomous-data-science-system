## 9. Decision rules

### N_LOWER_COST_COMPARABLE_CONTROL

Use only if:

    N correctly handles all 3 gaps and all 3 controls
    AND
    N provides the same timing, deterministic consequence power and lineage needed by the admitted competency questions
    AND
    N has strictly lower burden on the frozen vector.

If this occurs, structured OPERATIVE is not economically justified by these witnesses.

### OPERATIVE_INCREMENTAL_CONTROL_VALUE

Use if:

    N can detect the historical misses
    BUT
    detection is retrospective/advisory/inferential
    AND
    OPERATIVE adds generic deterministic continuous coverage/lineage or governed admission behavior required by already-admitted competency questions
    at a bounded, explicitly reported incremental burden.

This supports continued development, not automatic production adoption.

### OPERATIVE_REQUIRED_FOR_RELIABLE_DETECTION

Use if:

    N fails at least one positive or produces material control false positives
    while OPERATIVE handles the same cases mechanically.

### NO_ECONOMIC_DOMINANCE

Use if:

    both approaches have material non-overlapping advantages
    and the frozen burden vector does not support a non-arbitrary preference.

### EVIDENCE_INSUFFICIENT

Use if:

    historical evidence cannot support a fair paired comparison.
