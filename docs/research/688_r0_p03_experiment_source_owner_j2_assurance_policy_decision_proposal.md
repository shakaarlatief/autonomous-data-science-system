## 5. Independent design challenge and temporal falsifiers

A merely colocated `realizes_s1` JSON file does not own the G006/G013 production code. The owner of the *actual composite experimental realizer* must be distinguished from the historical library authors, and component execution evidence must be independently replayable. A source-author's `FULL` flag cannot prove these facts.

A separate fact-class distinction is therefore required:

- OBSERVABLE: exact Git source path, blob, commit, parent, changed path set, full-source G006/G013 outcomes and their reproducible result bindings.
- RELATIONAL: the scoped source author explicitly declares that the exact experimental realizer COVERS the accepted components, and any owner-delegation standing is evaluated under an accepted, *clearly weaker* experimental policy.
- EPHEMERAL: provider actions need their own qualified receipts only where such event facts are actually required, not from a model-authored status flag.
- J3: a separate evaluator applies the owner-accepted ALL_REQUIRED and lineage/currentness rules to precisely classified evidence, leaving insufficient cases UNKNOWN/HOLD.

If the future delegated author is only the descriptive carrier writer, if the model identity is misrepresented as independently authenticated, if the realizer has no actual executable role, if exact Git evidence cannot be verified, or if the new G013 run is not source-bound to the new transition, the result is **HOLD/FAIL**, not an automatic policy-mediated PASS.
