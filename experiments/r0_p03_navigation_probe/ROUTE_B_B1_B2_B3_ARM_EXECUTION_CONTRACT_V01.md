Compute one query-to-subject cosine similarity from normalized fixed tokens of subject `label + description + include_when` (vocabulary only; do not include subject exclusion/legacy topic metadata in similarity). Include the pure subject channel and fused B1 outputs in the saved result; no preferred-route authority promotion. Parent rollup is navigation only.
3. `B2_EDITORIAL_LINK_NAVIGATION`: use actual source-local path-reference edges only. Save pure-concern and fused B3 candidate rankings separately. No source file is relabelled as actually governing.
