# AO-10 DRP-05 ActionShape and Mediation Probe V0.1

Temporary qualification harness for Research 316 DRP-05a and DRP-05b.

The real corpus is every non-merge commit from the MC-0028 opening commit through
the frozen corpus base. It is selected mechanically, not by ease of
classification.

DRP-05a asks whether durable structured Git events can be normalized into
provider-neutral ActionShape records. DRP-05b asks whether the same real action
paths were actually preventable by an ADS AO preflight.

A generic Git/Codexless/provider safety check is not counted as AO mediation.
MEDIATED requires evidence that an ADS-controlled AO preflight could prevent
the effect. Current V0.3 has no production AO preflight, so the harness must
distinguish cooperative governed practice from technical prevention.

This is research machinery only and has no target-architecture preservation
right. Do not execute until the corresponding harness-freeze record is
committed.
